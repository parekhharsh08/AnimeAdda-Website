FREE PUBLISHING OPTION — GITHUB PAGES
1. Create/sign in to a free GitHub account at https://github.com/
2. Create a new public repository, for example animeadda-store.
3. Upload index.html to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”, select main and /(root), then Save.
6. Wait for GitHub Pages to publish. The website URL will be shown in Settings → Pages.
